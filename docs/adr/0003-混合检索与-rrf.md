# ADR 0003：向量 + BM25 双路召回，用 RRF 融合

- **状态**：已采纳
- **日期**：2026-11-19

## 背景

向量擅长语义近似（“钱什么时候回来”≈“退款到账”），但会混淆型号
（`X200-Pro` 与 `X201-Pro` 在语义空间几乎无差别）；BM25 相反：精确词强、同义词弱。

两路的分数不可直接比较：余弦是 0~1，BM25 是 0~几十。

## 决策

1. 两路各取 40 条候选（`recall_k`）；
2. 用 RRF `Σ weight / (60 + rank)` 融合，**只用名次，不用原始分数**；
3. 含型号/错误码的问题，路由把 BM25 权重从 0.5 提到 0.7。

## 后果

**好处**

- 无需归一化与调参；新增第三路只需多加一项。
- 对单路异常高分免疫。
- 规则路由零延迟、可解释，不像 LLM 分类会引入数百毫秒。

**代价**

- 丢弃“有多像”的信息：0.99 与 0.51 若名次相同则等权 → 由 Phase 2 的 rerank 补。
- 融合分数（约 0.03）不能当相似度阈值使用。
